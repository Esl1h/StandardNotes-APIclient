# Architecture decision records

Decisions that shape how the Standard Notes plugins (Kanban, API Client and Milkdown) are built and released, one file each, in the format of [Michael Nygard's ADRs](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions). The three repositories carry the same records. A record is never rewritten once accepted; a later one supersedes it.
